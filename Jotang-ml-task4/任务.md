## 1. Figure 1 里 Encoder 和 Decoder 分别在哪？

论文图注原话：**左半边是 Encoder，右半边是 Decoder**。

- **左边 Encoder**：输入 → 词嵌入 → 加位置编码 → 「多头自注意力 → 残差+LayerNorm → FFN → 残差+LayerNorm」× 6 层 → 输出给解码器。
- **右边 Decoder**：输出（右移一位）→ 词嵌入 → 加位置编码 → 「Masked 多头自注意力 → 残差+LayerNorm → 交叉注意力（K、V 来自编码器）→ 残差+LayerNorm → FFN → 残差+LayerNorm」× 6 层 → Linear → Softmax → 下一个词。

一句话：**Encoder 每层 2 个子层，Decoder 每层 3 个子层（多了交叉注意力）**。

## 3. 第 3 节四个组件的要点

**Scaled Dot-Product Attention**

`Attention(Q,K,V) = softmax(QKᵀ/√d_k)·V`

- `QKᵀ`：每个 query 和每个 key 算匹配分，得到 n×m 的分数矩阵。
- `/√d_k`：d_k 大时点积数值会变得很大，softmax 被推到饱和区、梯度接近 0；除以 `√d_k` 把数值拉回来。
- 行 softmax：每行变成和为 1 的权重。
- `·V`：按权重把 V 加起来，输出维度是 d_v。

**Multi-Head Attention**

- 8 套**不同**的 `W_i^Q、W_i^K、W_i^V`，把 512 维投影到 8 个 64 维子空间，各自做一次注意力，拼回 512 维再乘 `W^O`。
- 每个头看的角度不一样，所以不是把同一件事做 8 遍。

**Position-wise FFN**

`Linear(512→2048) → ReLU → Linear(2048→512)`，对每个位置单独做、位置之间共享参数。它提供非线性，**不混合词与词**。

**Positional Encoding**

用不同频率的 sin/cos 给每个位置生成一个 512 维向量，**直接加到词嵌入上**，让模型知道词的先后顺序。

**读不懂，后来怎么懂的**

| 卡点 | 后来怎么想通的 |
| --- | --- |
| Q、K、V 都来自同一个输入，为什么还要三个矩阵？ | 投影到的是不同子空间：Q 是"我在找什么"，K 是"我能被什么找到"，V 是"我实际给什么"。用同一个投影的话 `QKᵀ` 是对称的，表达不了"谁问谁答"这种方向性。 |
| 为什么除以 `√d_k`？ | 假设每维独立、方差为 1，点积的方差约等于 d_k；除以 `√d_k` 正好把方差拉回 1，softmax 不会"一口价"、梯度保得住。 |
| 位置编码为什么能表示相对位置？ | 每一对 (2i, 2i+1) 维相当于一个旋转，位置加 k 就等于旋转一个固定角度，所以 `PE(pos+k)` 可以写成 `PE(pos)` 乘一个与 pos 无关的矩阵——模型学个线性变换就能用上"相对位置"。 |
| mask 到底怎么加？ | 加在 **softmax 之前**：把未来位置的**分数**设成 −∞，softmax 之后这些位置的权重正好是 0。 |
| 解码器已经有 mask 了，为什么交叉注意力不 mask？ | 因果性只限制"不能看目标句里还没生成的词"；源句是完整给进来的，看全句不违反因果。 |
| 训练时整句喂进去，模型不就看到答案了？ | 输入整体右移一位，再加因果 mask，"预测第 i 个词"时只看得到第 i 个之前的东西。没 mask 的话模型会直接抄答案，训练 loss 很低、测试就崩。 |
| 残差和 LN 的顺序重要吗？ | 本文是"先加残差、再 LN"（Post-LN）；后来很多模型改成"先 LN、再进子层"（Pre-LN），因为深了以后 Post-LN 不好训、要 warmup。 |
## 5. 八个问题

**Q1：最初处理什么任务？为什么不用 RNN 和 CNN？**

机器翻译（WMT2014 英德、英法），另外用英语成分句法分析验证了泛化性。

不用 RNN 是因为 RNN 必须一步一步算，`h_t` 依赖 `h_{t-1}`，**训练时句子内部没法并行**，序列一长就慢。不用 CNN 是因为卷积要堆很多层才能让相距很远的词发生交互。自注意力一步就能让任意两个位置直连（路径长度 O(1)），而且整句可以一次算完，又快又容易学长依赖。

**Q2：Self-Attention 的"Self"是什么意思？和普通 Attention 什么区别？**

"Self" 就是 **Q、K、V 三者同源**——都来自同一个句子。

普通（交叉）Attention 是拿解码器的 Q 去查编码器的 K、V，管的是"两个句子之间的对齐"；Self-Attention 是句子内部自己人开会，管的是"这个词和句子里其他词什么关系"。本文解码器两种都用：先 masked self-attention 在已生成的目标句内部看，再交叉注意力去看源句。

**Q3：Q、K、V 从哪来？为什么要不同的线性变换？**

- 自注意力：Q、K、V 都是上一层输出（第一层是"词嵌入+位置编码"）。
- 交叉注意力：Q 来自解码器，K、V 来自编码器最后一层。

要不同投影，是因为三者角色不同：Q 负责"提问"，K 负责"被匹配"，V 负责"提供内容"。如果 Q、K 用同一个投影，`QKᵀ` 就是对称的相似度，表达不了方向；K 和 V 分开，还能让"拿什么特征去匹配"和"取走什么信息"各自独立。多头再接 8 套投影，每个头就有自己的一套规则。

**Q4：为什么要 softmax？每行权重表示什么？**

因为 `QKᵀ/√d_k` 是任意实数，softmax 把它变成**非负、每行加起来等于 1** 的分配比例，`αV` 就变成一个加权平均，数值不会爆，而且可微、能训练。指数还会放大差距，让注意力聚焦在少数几个词上。mask 也正好配合：把分数设成 −∞，softmax 后权重就是 0。

**每一行 = 一个 query 的分配方案**：这一行把 100% 的注意力按比例分给所有 key，`α[i][j]` 就是"位置 i 从位置 j 取了多少信息"。行和恒等于 1。

**Q5：多头为什么要分多个头？是重复吗？**

不是重复。8 个头各有**自己的一套** `W_i^Q、W_i^K、W_i^V`，把输入投影到 8 个不同的 64 维子空间，各看各的。论文原话是：多头让模型能同时关注不同表示子空间的信息，**单头做平均会把这些信息抹掉**。

证据：Table 3 里单头 24.9 BLEU，8 头 25.8，头加到 16、32 又掉回 25.1、25.4。所以头不是越多越好，但也绝不是复制——复制 8 份结果完全一样，反而白费算力。

**Q6：没有循环，怎么知道词的先后顺序？**

靠**位置编码**。模型本身分不清顺序（注意力对打乱词序是等变的），所以在最底层给每个位置加一个固定的 512 维 sin/cos 向量，同一个词出现在不同位置就有了不同的输入。和词嵌入**直接相加**，不改变维度。

**Q7：Decoder 为什么要 Masked Attention？看到后面的答案会怎样？**

因为解码器是自回归的：生成第 i 个词时只能用前 i−1 个词。但训练时为了并行，整句是一次性喂进去的，如果不遮住，位置 i 就能看到 `y_{i+1}…y_n`，也就是标准答案。

后果：模型会直接抄答案，训练 loss 掉到接近 0，但推理时没有"未来"，直接把答案抄没了，效果崩掉。所以要 mask：把未来位置的分数设成 −∞，softmax 后权重为 0。

**Q8：残差、LayerNorm、FFN 在图的哪儿？各有什么用？**

| 组件 | 位置 | 作用 |
| --- | --- | --- |
| 残差连接（⊕ 弧线） | **每个子层外面**都套一圈：编码器 2 个/层，解码器 3 个/层，一共 30 个 | 给梯度一条直通路，深层也能训；子层只需学"增量" |
| LayerNorm | 每个 ⊕ 后面（`LayerNorm(x + Sublayer(x))`） | 把每个词的 512 维向量归一化，训练更稳；不跨样本，所以和 batch 大小无关 |
| FFN | 每个注意力子层之后，每层 1 个，共 12 个 | 逐位置做非线性变换，是参数量的主体；**只加工单个位置，不混合词与词** |
