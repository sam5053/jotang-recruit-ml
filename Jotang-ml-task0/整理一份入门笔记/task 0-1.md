1. 人工智能、机器学习和深度学习
	  人工智能（AI）是最大的概念，机器学习（ML）是实现 AI 的一类方法，让机器从数据中学习规律，并作出预测或判断，深度学习（DL）是机器学习的一个分支，主要使用多层神经网络自动学习特征。因此人工智能包含机器学习包含深度学习。
2. 监督学习与无监督学习
	  监督学习：从给定的“正确答案”中学习并给出输出。如根据房间大小预测房价。
	  无监督学习：从数据中发现特定的有趣的结构或规律，如判断肿瘤是否是恶性。
3. 数据：一个个样本，比如在预测房价的例子中，一个房子的大小和价格是数据。
	  特征：描述样本的输入变量，如房子的大小，肿瘤的大小等。
	  标签：希望模型预测的答案，如房价，肿瘤是否是恶性。
	  训练集：根据训练集数据，用梯度下降法来调整参数。
	  验证集：相当于模拟，不改变参数，用于选择合适的拟合函数。
	  测试集：在最后使用，且一般只使用一次，用于模拟一般情况，测试模型的实际表现。
4. Batch size 是一次参数更新所使用的样本数量。
	 Batch size 太小：梯度噪声大，更新频繁，训练可能不稳定，但内存占用小，有时泛化更好。
	 Batch size 太大：梯度更稳定，硬件利用率高，但内存占用大，更新次数少，可能需要重新调整学习率。
	 Batch size 等于 1：随机梯度下降（SGD）。
	 Batch size 等于全部样本：批量梯度下降。
	 介于两者之间：小批量梯度下降，也是深度学习中最常见的做法。 
5. **模型**是从输入到输出的计算结构或函数，例如线性回归、决策树或神经网络。**模型参数**是模型在训练过程中自动学习的数值，例如权重和偏置。
6. 一个神经网络包含
	 输入层：接收特征。
	 隐藏层：逐层提取和组合特征。
	 输出层：产生预测结果。
	 权重和偏置：决定每个神经元如何组合输入。 
	 激活函数 ：加入非线性。
	 损失函数：衡量预测与目标的差距。
	 优化器：根据梯度更新参数。
	- 激活函数就是神经元在做完线性组合后，得到的值作为线性函数的输入，然那个神经网络具有非线性的表示能力。
	- 常见的激活函数：Sigmoid,ReLU
7. 矩阵求导：
	 本质是当某个输入或参数变化一点时，输出或损失会变化多少。
	g = a^T x                 => ∂g/∂x = a
	g = x^T A x               => ∂g/∂x = (A + A^T)x
	y = xW                    => ∂L/∂x = (∂L/∂y)W^T
	Z = XW                    => ∂L/∂W = X^T (∂L/∂Z)
	Z = XW                    => ∂L/∂X = (∂L/∂Z)W^T 
8. 设样本为A,每一层中两个参数分别为W,b.(其中A,W,b均为矩阵)
	 前向传播的过程：
	 Z=AdotW+b
	 A_next= activation(Z)
	 A_next可作为下一层的输入矩阵
9. 
	 **前向传播**：从输入开始，逐层计算结果，最后得到预测值，并保存反向传播需要的中间值。
	 **反向传播**：利用链式法则，从损失开始反向计算每个参数对损失的偏导。
	 **损失函数**：衡量预测值和真实标签的差距，例如回归常用 MSE，分类常用交叉熵。
	 **梯度**：表示损失上升最快的方向。参数应沿梯度的反方向更新。
	 **学习率**：控制每次参数更新走多远。(不能太大也不能太小)
10. 优化器是用来“更新模型参数”的算法，通过不断调整参数，让损失函数尽可能变小。
    SGD                     简单，泛化好，但慢
	Momentum         加速 SGD，减少震荡
	AdaGrad              适合稀疏特征
	RMSProp             自适应学习率，适合复杂曲面
	Adam                  收敛快，深度学习常用
11. 过拟合是指模型在训练集上表现很好，但在测试集或真实数据上表现差。
	欠拟合是指模型太简单，连训练集都学不好
	 正则化是一类防止模型过拟合的方法。它的核心思想是：不要让模型变得过于复杂。
