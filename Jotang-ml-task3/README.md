# Jotang ML Task 3：`loss.backward()`
## 实践 1：简单计算链

题目中的 `x2` 按 `x²` 理解，即 `f(x,y)=(xy+x²)²`。取 `x=1.5`、`y=-0.5`。
- **NumPy 怎样从后往前算梯度？** `df/ds=2s=3`，把这份梯度传给之前。有两条路径，贡献要相加。代码用 NumPy 逐节点计算。
- **PyTorch 检查结果一致吗？** 一致。`f=2.25`、`df/dx=7.5`、`df/dy=4.5`，最大绝对误差都是 `0`。

## 实践 2：两层二分类网络

- **怎样选样本、隐藏层和参数？** 沿用 Task 1 的 `make_moons(n_samples=1000, noise=0.2, random_state=4)`。先取第 0 行，再取第 `[0,1,9,11]` 行组成 4 样本 batch。隐藏层用 3 个神经元；参数固定为：

  ```text
  W1 = [[ 0.7, -0.4, 0.3],    b1 = [0.1, -0.1, -0.2]
        [-0.2,  0.5, 0.8]]
  W2 = [[0.6], [-0.7], [0.4]]  b2 = [-0.05]
  ```
- **从输入到 loss 的计算图是什么？** `n` 是样本数；节点后面标了形状，梯度与对应节点同形状。

  ```mermaid
  flowchart LR
      X["X (n,2)"] --> Z1["Z1=X·W1+b1 (n,3)"]
      W1["W1 (2,3)"] --> Z1
      b1["b1 (3,)"] --> Z1
      Z1 --> A1["A1=ReLU(Z1) (n,3)"]
      A1 --> Z2["Z2=A1·W2+b2 (n,1)"]
      W2["W2 (3,1)"] --> Z2
      b2["b2 (1,)"] --> Z2
      Z2 --> P["P=Sigmoid(Z2) (n,1)"]
      P --> L["平均 BCE loss ()"]
      Y["Y (n,1)"] --> L
  ```

- **每个参数的梯度怎么求？** 按计算图倒着走，先有 `dZ2=(P-Y)/n`，然后：

  ```text
  dW2 = A1.T @ dZ2       db2 = sum(dZ2, axis=0)
  dA1 = dZ2 @ W2.T       dZ1 = dA1 * (Z1 > 0)
  dW1 = X.T @ dZ1        db1 = sum(dZ1, axis=0)
  dX  = dZ1 @ W1.T
  ```

  单样本时 `X/dX` 是 `(1,2)`，`Z1/A1` 及其梯度是 `(1,3)`，`Z2/P` 及其梯度是 `(1,1)`；4 样本时第一维变成 4。`W1/dW1` 始终是 `(2,3)`，`b1/db1` 是 `(3,)`，`W2/dW2` 是 `(3,1)`，`b2/db2` 是 `(1,)`。`Y` 与 `P` 同形状，loss 是标量 `()`。
- **PyTorch 怎样检查？** 重新前向传播，再调用 `loss.backward()`。中间结果用 `retain_grad()` 取出梯度一起检查。
- **NumPy 与 PyTorch 的梯度一致吗？** 一致。完整数值在输出文件中。

  | 参数梯度 | 单样本 NumPy 值 | 4 样本 NumPy 值 | 最大绝对误差：单样本 / 4 样本 |
  | --- | --- | --- | --- |
  | `dW1` `(2,3)` | `[[-0.1731583998,0,0],[0.1286115103,0,0]]` | `[[0.0011744748,-0.0115429052,0.0065959458],[0.1233568453,-0.1542704508,0.0881545433]]` | `0 / 3.469e-18` |
  | `db1` `(3,)` | `[-0.2451884332,0,0]` | `[-0.0478623732,-0.1738365974,0.0993351985]` | `0 / 1.388e-17` |
  | `dW2` `(3,1)` | `[[-0.2857533753],[0],[0]]` | `[[-0.0477257900],[0.0787634337],[0.1315884467]]` | `0 / 0` |
  | `db2` `(1,)` | `[-0.4086473886]` | `[0.0237188964]` | `0 / 1.388e-17` |

  单样本中后两个隐藏神经元没有被 ReLU 激活，所以它们在第一层的梯度为 0。4 样本时公式不变，但要把各样本的参数梯度相加；平均损失让 `dZ2` 多一个 `1/n`。

## 趁热打铁

- **为什么前向要保存每层输入或输出？和显存有什么关系？** 反向要用 `X` 算 `dW1`、用 `Z1` 判断 ReLU 哪里能传梯度、用 `A1` 算 `dW2`。这些中间结果占内存；放在 GPU 上时就占显存。
- **链式法则怎样把梯度传回第一层权重？** 从 loss 倒着算 `dZ2 → dA1 → dZ1 → dW1`。每过一层就乘那层的局部导数；ReLU 没激活的位置会把梯度截成 0。
- **BCE 与 Sigmoid 配合后，loss 对 logit 的梯度是什么？** 平均损失时是 `(P-Y)/n`；单样本时是 `P-Y`。式子简单，可以直接代入后面各层的矩阵计算。
- **两边梯度不一致时怎么找问题？** 先对照前向结果，再从 `dZ2` 开始逐层比。形状错查转置；bias 错查求和维度；整体差 `n` 倍查是否取平均；只在 ReLU 附近错就查正负掩码。
- **现在怎样理解 `loss.backward()`？** 它沿计算图倒着用链式法则，利用前向保存的结果，算出并累加参数的 `.grad`。更新参数仍要另用优化器。
